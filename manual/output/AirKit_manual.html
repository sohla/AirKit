device

One column per connected Airstick. Columns appear on their own when a stick starts sending.

12345678
  1. 1

    Tabs

    Switch between the four pages: device, visual, control and system.

  2. 2

    Device number

    Which Airstick this column is.

  3. 3

    Network

    The IP address and port the stick's data is arriving from.

  4. 4

    Battery

    Charge reported by the stick.

  5. 5

    Plotter

    Live trace of the signals the loaded personality chooses to show. Goes flat while the device is muted.

  6. 6

    3D view

    The stick's orientation. The box turns with the stick; the small yellow, magenta and cyan bars show acceleration. Tap to calibrate.

  7. 7

    Personality

    The loaded personality, in the device's colour. Tap to mute or unmute; it greys out when muted.

  8. 8

    Previous / next

    Load the previous or next personality in this kit's roster.

visual

The visuals the personalities draw.

1
  1. 1

    Visual surface

    All devices drawn on one canvas (Overlay) or one canvas each (Grid); switch on the system page. When the visuals are on a second screen this reads "visuals on HDMI".

control

Per-device settings. Moves here are shared with the web app and MIDI, and are remembered between sessions.

123
  1. 1

    Sliders

    Drag across to set each parameter: volume, sensitivity and any the personality adds. Some personalities show their own controls here instead.

  2. 2

    Personality

    Same as on the device page: tap to mute or unmute.

  3. 3

    Previous / next

    Same as on the device page.

system

Health of the kit, and the buttons that act on the whole system.

1234567891011121314
  1. 1

    Load

    System Load is CPU use across the Pi; SC Load is AirKit's share. Temp and Fan are the Pi's temperature and fan state.

  2. 2

    Audio server

    Audio engine CPU, and how many UGens, groups and synths are running.

  3. 3

    Hosting / Port

    This kit's IP address and port: what the web app and Airsticks should point at.

  4. 4

    Meters

    Input and output levels.

  5. 5

    Node tree

    What is currently running on the audio server.

  6. 6

    Version

    The installed AirKit version.

  7. 7

    Overlay / Grid

    Visuals as one shared canvas, or one canvas per device.

  8. 8

    Panel / HDMI

    Show the visuals on this panel or on a second screen. Pressing HDMI checks for a screen; with none plugged in it snaps back to Panel.

  9. 9

    Network Pi only

    Restarts the Pi's networking. Try this if sticks or the web app lose connection.

  10. 10

    OSC Thru

    Forward the incoming Airstick data to another computer (set in the kit's machine file).

  11. 11

    Free All buffers

    Unload every sample from memory.

  12. 12

    Free All Nodes

    Stop every sound immediately.

  13. 13

    QUIT Pi only

    Quit AirKit.

  14. 14

    TURN OFF Pi only

    Shut the Pi down. Wait for the screen to go dark before unplugging.
