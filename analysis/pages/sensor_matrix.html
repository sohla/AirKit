Sensor Matrix

One row per p-file, one column per signal. Each cell shows how many live (uncommented) lines of the file read that signal. Columns are grouped into what the model publishes, what p-files define for themselves, and raw d.sensors reads. Reads inside ~plot are probes for the screen, not mappings, so they are hidden unless you switch them on.

filter constants: attack × decay, one dot per setting, area = number of files

Click a row to see the lines behind it.
